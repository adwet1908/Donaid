# 🎁 Donaid

Donaid is a full-stack donation web application built using the MERN stack with Razorpay integration. Users can donate to campaigns with secure payment processing and receive instant feedback on success/failure.

---

## 🚀 Tech Stack

- **Frontend:** React (Vite), Tailwind CSS
- **Backend:** Node.js, Express.js, MongoDB
- **Payments:** Razorpay

This does not have any identity authentication and was solely built with purpose of practising payment gateways via razorpay API
